# 0.4.7 · 설치 단순화와 프로젝트 정리

- 확장 앱에서 같은 버전의 Windows 도우미를 직접 다운로드합니다.
- PDF는 추가 설치 없이 사용합니다. HWPX를 처음 사용할 때 설치 안내를 제공합니다.
- 도우미는 기본 설정으로 설치하고 확장 ID·경로는 고급 설정에 둡니다.
- 설치 후 안내 화면으로 돌아오면 연결을 확인합니다. 다운로드 직후 확인은 2분 동안만 수행하며 성공·페이지 종료 시 중단합니다.
- 도우미 연결 상태에 두 앱의 버전을 표시하고 불일치 시 업데이트를 안내합니다. HWPX 변환은 버전 일치 후 시작합니다.
- `release.json` 하나에서 확장·패키지·Windows 실행 파일·설치된 앱의 버전을 관리합니다.
- 검은 까마귀·노란 부리·밝은 배경의 Chrome PNG와 Windows ICO를 적용합니다. 설명용 큰 이미지에는 `f(x) = HWP`를 넣습니다. 실제 출력 형식은 HWPX입니다.
- 프로젝트를 `AI_Chat2Hwpx_Pdf`로 변경하고 `chrome-extension` / `windows-helper`로 구분합니다.
- 구 배포 파일·로컬 기록·임시 진단은 복구 가능하게 `_archive`에 보관합니다.

## 검증

`npm test`: 구문/구조·수식·백그라운드 작업·사이트·인쇄 생명주기·설치 안내 및 연결 실패 검증.
`npm run test:print`: Chrome/Edge에서 PDF 72건, HWPX 추출 72건. 네 가지 테마/인쇄 CSS, 세 배율, 세 출력 범위.
도우미 프레임 프로토콜 ping과 설치 프로그램의 격리된 설치/복구/실패 복원/제거 검증. 새 설치 화면 기본/고급 설정 이미지 확인.

사용자는 앞선 PDF 수정이 다른 컴퓨터에서도 정상 작동함을 확인했습니다. 이번 0.4.7의 새 PC 설치 과정은 배포 후 사용자가 확인해야 합니다. 자동 검사는 실제 웹스토어 업데이트·브라우저 권한 팝업·다운로드 실행을 대신하지 않습니다.

## 배포

확장 ZIP, Windows 설치 EXE, 재구성한 소스 ZIP, 웹스토어 아이콘/홍보 이미지, SHA-256을 생성합니다. 도우미는 `v0.4.7/Chat2HwpPdf-Setup.exe` 배포 주소를 사용합니다. GitHub에 해당 파일이 공개되면 다운로드 버튼이 작동합니다. Chrome 웹스토어에는 새 ZIP과 아이콘/홍보 이미지 업로드 및 심사 제출이 필요합니다.
