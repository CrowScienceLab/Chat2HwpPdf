# 0.7.0 · 그림 포함 내보내기와 문서 서식 개선

확장·도우미·설치 프로그램·다운로드 경로의 버전은 0.7.0이며 Windows FileVersion은 0.7.0.0입니다.

## 주요 변경

- ChatGPT·Claude·Gemini·Gemini Notebook의 그림·인포그래픽을 PDF와 HWPX에 포함하도록 개선했습니다. 대화형 시각화는 필요한 경우 정적 이미지로 보존하며 HWPX 수식은 편집 가능한 수식 개체로 유지합니다.
- 그림 포함이 기본입니다. “출력 설정” 오른쪽의 항상 보이는 **그림 제외** 체크박스를 선택하면 텍스트·수식만 출력합니다.
- 큰 그림은 문서 폭에 맞추고, 긴 시각화와 지연 로딩 그림 처리를 보완했습니다. 그림을 보존하지 못하면 생략 사유를 안내합니다. 내보내는 동안 해당 탭을 유지하세요.

- 본문과 표 안 글자 11pt, 줄간격 150%.
- 전체 대화 제목 20pt, 중간제목 15pt와 위쪽 빈 문단 한 줄.
- HWPX 문서 여백: 위/아래 15mm, 왼쪽/오른쪽 20mm, 머리말/꼬리말 10mm.
- PDF는 위/아래 15mm, 왼쪽/오른쪽 20mm 인쇄 여백. 머리말/꼬리말은 Chrome 인쇄 창 설정을 따릅니다.
- 출력 설정의 “그림 제외”는 기본 해제. 선택하면 그림·인포그래픽을 빼고 텍스트·수식을 유지합니다. 기존 그림 포함 설정을 이어받습니다.
- 미연결 빨강 LED, 연결 초록 LED, 연결됨 문구는 굵은 빨강.
- 팝업의 노란 부리 까마귀는 별도 256px PNG 사용.
- 설치 성공 시 닫기 버튼 전환 유지.

같은 버전의 팝업 수정: 그림 제외 옵션을 접힌 설정 바깥, “출력 설정” 오른쪽으로 옮겨 항상 표시합니다. 연결 성공 시 별도 상태 영역에 반복하던 두 번째 연결 문구를 제거하고 첫 번째 LED/버전 행만 유지합니다. 버전 불일치·연결 실패·내보내기 결과 안내는 계속 표시합니다.

인쇄 보안 정책 수정: ChatGPT의 `base-uri 'none'` 정책에 차단되던 인쇄 프레임의 base 태그를 제거했습니다. 상대 그림/링크 주소는 문서를 옮기기 전에 절대 주소로 바꾸고 SVG 수식의 #참조는 유지합니다. 사이트 보안 정책을 변경하지 않습니다. `tests/print-csp.mjs`가 실제 CSP 헤더 아래에서 인쇄 호출·그림 로딩·링크·수식 참조와 보안 위반/콘솔 오류 없음을 검증합니다.

## 검증

`npm test`, `npm run test:ui`, `npm run test:media`, Chrome/Edge `npm run test:print`, 도우미 framed ping 및 실제 한글 COM 내보내기를 검증합니다.

`node tests/document-format.mjs`로 fixture를 만들고 도우미 `--self-test`로 HWPX를 생성합니다. Contents/header.xml과 section0.xml을 추출한 뒤 `node tests/verify-document-format.mjs <추출 폴더>`로 제목·본문·표·빈 문단·줄간격·여백을 검사합니다. 표 안 글자는 COM SelectAll의 적용 범위에서 제외되므로 저장된 서식 정의도 정규화합니다.

Chrome/Edge 인쇄72건·HWPX 추출72건, 그림 포함/제외44개 브라우저 경우, CSP 헤더 재현 검사, 실제 한글 COM 저장·재열기·수식 편집을 확인했습니다. 자동 사이트 검사는 사이트 구조를 재현한 fixture로 수행합니다.

## 설치 및 업데이트

1. **PDF**는 Chrome 확장만 필요합니다. **HWPX**는 Windows용 한글과 같은 버전의 도우미가 필요합니다.
2. 도우미를 업데이트하려면 **Chat2HwpPdf-Setup.exe**를 실행합니다. 이미 도우미0.7.0을 설치했다면 이번 팝업/CSP 수정 때문에 다시 설치할 필요는 없습니다.
3. 수동 테스트는 **Chat2HwpPdf-Chrome-0.7.0.zip**을 압축 해제하고 `chrome://extensions`의 개발자 모드에서 **manifest.json이 있는 폴더**를 로드합니다. 프로젝트 전체 폴더나 소스 ZIP을 로드하지 않습니다.
4. 기존 확장 폴더를 교체했다면 확장 카드의 새로고침 버튼을 누르고, 열려 있는 AI 대화 탭도 새로고침합니다. 개발용 확장 ID가 웹스토어 ID와 다르면 도우미 고급 설정에 해당 ID를 입력합니다.
5. Chrome에 남은 과거 오류 기록은 지운 뒤 PDF 출력을 다시 실행해 재발 여부를 확인합니다.

GitHub 배포와 Chrome 웹스토어 심사는 별도입니다. GitHub에서 이 버전을 공개해도 웹스토어 설치본이 바로 업데이트되지는 않습니다. HWPX와 PDF가 실제 출력 형식이며, 그림은 정적 이미지로 들어갑니다. 개인정보는 외부 변환 서버로 전송하지 않습니다.

첨부 파일: Chrome 확장 ZIP, Windows 설치 EXE, 소스 ZIP, 아이콘/소개 이미지, SHA256SUMS.txt. 소스 빌드에 필요한 공식 한글 자동화 보안 모듈은 소스 ZIP의 windows-helper/security에 포함합니다.
