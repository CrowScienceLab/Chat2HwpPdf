# 0.4.8 · 첨부 이미지 기반 아이콘

사용자가 제공한 검은 까마귀·노란 부리·수식 문서·HWP 문서·변환 화살표 이미지를 기준으로 앱 아이콘을 교체합니다.

- 큰 아이콘: 첨부 이미지의 전체 구성을 유지하고 바깥 검은 모서리를 투명하게 정리합니다.
- 작은 아이콘: 같은 까마귀만 남긴 변형으로 16/32/48/64px에서 구분하기 쉽게 표시합니다.
- Chrome 128px, Windows ICO 128/256px, 설명용 512px에는 전체 문서 변환 구성을 적용합니다.
- Chrome 팝업·설치 안내, Windows 설치 EXE·제거 앱, 프로젝트 안내 페이지, 웹스토어 440×280 홍보 이미지도 갱신합니다.
- Chrome 확장과 Windows 도우미 버전은 모두 0.4.8로 동기화합니다. 0.4.7 공개 파일은 그대로 보존합니다.

이미지 원본은 branding/reference-original.png, 큰 아이콘 원본은 branding/app-master.png, 작은 까마귀 원본은 branding/crow-master.png입니다. npm run vendor와 npm run build로 모든 크기를 재생성할 수 있습니다. 이전 아이콘은 작업 공간의 _archive에 보관합니다.

기능과 권한은 0.4.7과 동일합니다. 새 ZIP과 스토어 소개 이미지는 Chrome 웹스토어에 별도 갱신해야 합니다.
