# 수식Chat to HWPX/PDF

AI 채팅의 수식을 한글에서 편집 가능한 수식 개체가 포함된 HWPX로 변환하거나 PDF로 출력하는 Chrome 확장 프로그램입니다.

This Chrome extension exports AI conversations to PDF or HWPX documents containing editable equation objects for Hancom Hangul.
