개인정보처리방침

수식Chat to HWPX/PDF · Crow Science Lab. · 0.4.4
시행일: 2026-09-26

사용자가 명시적으로 선택한 AI 대화만 로컬에서 내보냅니다. 대화, 문서, 수식 또는 개인정보를 Crow Science Lab.의 서버로 전송하지 않으며 광고·분석·추적 코드를 포함하지 않습니다.

권한

  • activeTab: 사용자가 내보내기를 실행한 현재 탭의 대화 읽기
  • scripting: 현재 탭에서 대화와 수식 추출 기능 실행
  • storage: 출력 설정과 최근 작업 상태 저장
  • nativeMessaging: HWPX 생성 또는 연결 확인 시 Windows 도우미와 로컬 통신

전체 사이트 접근, 방문 기록 또는 다운로드 목록 권한을 요청하지 않으며 원격 실행 코드를 사용하지 않습니다.

저장 정보

확장 저장소에는 출력 설정, 최근 작업 결과, 저장 경로, 수식 개수와 변환 경고가 저장됩니다. 대화 전문과 생성 문서 원문은 보관하지 않습니다. Windows 도우미는 설정과 보안 모듈을 현재 사용자의 로컬 앱 데이터 폴더에 저장하며, HWPX 파일은 사용자가 선택한 폴더에 저장합니다.

정상 완료 시 변환용 임시 파일을 정리합니다. 비정상 종료 시 일부 임시 파일이 남을 수 있습니다. 도우미 제거 시 사용자가 만든 문서는 삭제하지 않습니다.

개인정보 관련 문의는 GitHub Issues에서 접수합니다.

Privacy Policy

Formula Chat to HWPX/PDF · Crow Science Lab. · 0.4.4
Effective date: September 26, 2026

The extension processes only AI conversation content that the user explicitly chooses to export. Conversations, documents, equations, and personal information are not transmitted to servers operated by Crow Science Lab. The extension contains no advertising, analytics, or tracking code.

Permissions

  • activeTab: reads the active tab after the user starts an export.
  • scripting: runs conversation and equation extraction in that active tab.
  • storage: stores output preferences and the latest task status.
  • nativeMessaging: communicates locally with the Windows helper for HWPX creation or connection checks.

The extension does not request access to all websites, browsing history, or downloads, and it does not use remotely hosted executable code.

Stored information

Chrome extension storage contains output preferences, the latest task result, the saved file path, equation counts, and conversion warnings. It does not retain full conversations or generated document content. The Windows helper stores its settings and security module in the current user's local application data folder. HWPX files are saved in the folder selected by the user.

Temporary conversion files are removed after normal completion, although some files may remain after an unexpected termination. Removing the helper does not delete documents created by the user.

Privacy questions and requests may be submitted through GitHub Issues.
