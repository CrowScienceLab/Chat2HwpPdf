# 0.6.0 · 그림 포함과 설치 완료 화면 개선

0.6은 Chrome 버전·npm 버전·도우미 응답·설치 프로그램·Windows 파일 메타데이터에 모두 0.6.0(Windows FileVersion 0.6.0.0)으로 적용합니다.

## 변경

- 설치 성공 시 초록색 설치 완료 안내와 닫기 버튼으로 전환합니다. Enter/Esc/닫기를 누르면 설치 창을 종료합니다. 실패 시에는 설치를 재시도할 수 있습니다.
- 출력 설정의 그림·인포그래픽 포함은 기본 체크이며 PDF/HWPX에 공통 적용합니다. 기존 설정에 해당 항목이 없어도 기본 켜짐입니다.
- Gemini의 버튼 내부 이미지, Notebook 보고서/인포그래픽의 SVG foreignObject 내부 그림, Claude의 별도 iframe 시각화를 내보내기 전에 확보합니다.
- 원본 픽셀을 읽을 수 있으면 PNG로 보존하고, 교차 출처 이미지·iframe 등은 활성 대화 탭에서 보이는 그림 영역을 캡처합니다. 새로운 전체 사이트 권한은 추가하지 않습니다.
- 대화형 시각화는 현재 화면의 정적 그림으로 삽입합니다. 동작하는 슬라이더나 애니메이션 자체가 HWPX/PDF에 포함되는 것은 아닙니다.
- 긴 그림의 분할 캡처와 중첩 스크롤을 처리하고, 처리 후 스크롤 위치를 복원합니다. 내보내는 동안 다른 탭으로 전환하면 해당 캡처를 거절합니다.
- 그림 포함/실패 건수를 표시합니다. 가려진 그림, 로딩 실패, 너무 큰 그림은 사유를 문서에 표시합니다. 그림은 최대 40개, 인코딩 합계 약 24MB, 개별 1200만 픽셀로 제한합니다.
- 그림을 해제해도 편집 가능한 수식 변환은 유지합니다. 한글에는 PNG 그림을 내부 리소스로 삽입하며 큰 그림의 표시 크기는 문서에 맞춰 축소합니다.
- 개인정보처리방침에 일시적인 현재 탭 캡처·그림 영역 처리·스크롤 복원을 명시합니다. 전체 화면 이미지는 확장 저장소에 보관하거나 외부 서버로 전송하지 않습니다.

## 검증

- npm test: 구문/구조, 수식, 백그라운드 작업, 사이트/선택 영역, 인쇄 생명주기, 연결 안내 및 캡처 세션 보호 검사.
- npm run test:ui: 기존 설정의 그림 기본 체크, 켜기/끄기, 버전 표시, PDF 도우미 불필요, 도우미 미설치 안내.
- npm run test:media: 11개 미디어 구조 × 그림 포함/제외 × PDF/HWPX = 44건. 기본 배율과 2배 확대에서 검사. 외부 이미지·동일 출처 이미지·버튼·cross-origin iframe·긴 그림·중첩 스크롤·가림 실패·지연 로딩·Notebook SVG·선택 영역 포함. 정적 그림에 빈 가로 띠가 없는지 픽셀 알파값 검사.
- Chrome/Edge 기존 회귀: PDF 72건 및 HWPX 추출 72건.
- 설치 프로그램의 격리된 설치/복구/실패 복원/제거 검사. 성공 화면에서 닫기 클릭으로 실제 종료 확인.
- 네 사이트 구조의 생성 패키지를 실제 한글 COM으로 저장하고 HWPX의 BinData 그림 및 picture 개체 확인.
- PDF 샘플 네 개를 생성하고 렌더링하여 그림과 수식의 표시 확인.

자동 브라우저 검사는 실제 사이트에서 확인한 DOM 구조를 재현한 로컬 fixture와 테스트용 캡처 브리지로 수행합니다. 사용자 계정의 설치된 확장을 자동 교체하거나 실제 대화의 네 사이트 전체를 재출력한 검사는 아닙니다. 실제 Chrome 확장 업데이트 후 사용 중인 페이지를 새로고침하고 재확인하세요.
