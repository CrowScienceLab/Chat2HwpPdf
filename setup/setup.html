수식Chat to HWPX/PDF

Crow Science Lab. · 처음 사용하기

1. Windows 도우미 설치

HWPX 변환에는 Windows 데스크톱 한글과 수식Chat 도우미가 필요합니다.

배포 파일의 Chat2HwpPdf-Setup.exe를 실행하세요. 저장 폴더와 보안 모듈 설치 위치를 선택할 수 있습니다.

현재는 공개 전 검증 버전입니다. 공개 다운로드 주소는 아직 등록되지 않았습니다.

2. 연결 확인 · 저장 폴더

기본: 문서\Chat2Hwp&Pdf

3. 내보내기

  • PDF: Chrome 인쇄 창에서 PDF로 저장
  • HWPX: 기본 저장 폴더에 저장 후 한글에서 열기
  • 선택 영역: 대화에서 원하는 부분을 먼저 드래그

제거

Windows의 설치된 앱에서 ‘수식Chat 도우미’를 제거하고 Chrome에서 확장을 삭제하세요. 도우미 설치 파일과 전용 등록값·설정은 제거되며 저장한 문서는 보존됩니다.

대화 내용은 외부 서버에 전송하지 않습니다.
