PDF는 바로 사용할 수 있습니다

대화 페이지에서 확장 앱을 열고 PDF를 선택하세요. Chrome 인쇄 창에서 PDF로 저장합니다.

한글에서 편집하려면 도우미를 설치하세요

HWPX 변환에는 Windows 데스크톱 한글이 필요합니다. 도우미는 처음 한 번만 설치하면 됩니다.

한글 변환 도우미 받기
  1. 다운로드한 Chat2HwpPdf-Setup.exe를 실행합니다.
  2. 설치를 누릅니다. 기본 설정으로 설치됩니다.
  3. 이 화면으로 돌아오면 연결을 확인합니다.
고급 설정 · 개발용 확장

웹스토어에서 설치했다면 ID를 입력할 필요가 없습니다. 압축해제하여 로드한 개발용 확장은 아래 ID를 도우미 설치 프로그램의 고급 설정에 입력하세요.

연결 확인 · 저장 폴더

기본: 문서\Chat2Hwp&Pdf

제거

Windows의 설치된 앱에서 ‘수식Chat 도우미’를 제거하고 Chrome에서 확장을 삭제하세요. 저장한 문서는 보존됩니다.
